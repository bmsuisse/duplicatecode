Unsere Suchmaske lässt Benutzer beliebige Bedingungen auf Spalten kombinieren, und daraus soll die Datenbankabfrage entstehen. Die Werte der Benutzer dürfen auf keinen Fall direkt in den Abfragetext gelangen, damit niemand die Datenbank manipulieren kann. Gesucht ist ein Baustein, der aus den Bedingungen den Bedingungsteil der Abfrage samt den zugehörigen Werten liefert.

Sprache: Python
