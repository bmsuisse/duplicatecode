Unsere Seite hat ein Suchfeld, das die Umgebung erst informieren soll, wenn der Benutzer kurz zu tippen aufgehört hat, damit nicht jeder Buchstabe eine Anfrage auslöst. Zusätzlich soll man das Feld mit einem Klick leeren können. Gesucht ist eine wiederverwendbare React-Komponente dafür.

Sprache: TypeScript (React)
